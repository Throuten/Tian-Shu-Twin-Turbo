================================================================================
  给接手同学看的说明（口语版）—— 这包里有什么、配了什么
================================================================================

嗨，这个文件夹（或压缩包）主要是一套「智慧交通」演示：左边/页面里有地图，
后端用 Spring Boot 起在 8080，算路靠 Docker 里的 OSRM（本地重庆路网数据）。

另外根目录里有个 demo\demo\ 子文件夹，是以前拷的一份 Spring 工程，可以当不存在，
真正要改的是这一层的 pom.xml 和 src\ 文件夹。

--------------------------------------------------------------------------------
一、你先找得到的：警用端 / 车主端 切换在哪儿？
--------------------------------------------------------------------------------
（你同学说做了切换，就在下面两个地方，别在 police 页面里死找。）

1）打开 dev_hub.html（开发者枢纽）
   · 看左侧栏，滑到最下面有一块标题叫「终端切换」
   · 蓝色主按钮：「切换到车主端」→ 会整页跳转到 vehicle_terminal.html（车主界面）
   · 灰色按钮：「切换到政府端」→ 把右侧 iframe 切回警用终端，并恢复左侧警用相关按钮

2）在 vehicle_terminal.html（车主端）里
   · 顶部标题那一行右边有个按钮：「切换到政府端」
   · 点它会回到 dev_hub.html（不是直接进 police_terminal，而是回到枢纽页）

小结：枢纽页 dev_hub = 警用内嵌 + 切车主；车主页 = 单独整页 + 切回枢纽。
直接双击 police_terminal.html 是警用全屏，那里没有「切车主」按钮，所以容易找不到。

--------------------------------------------------------------------------------
二、这个包里大致有哪些东西（心里有个地图）
--------------------------------------------------------------------------------
· HTML 页面：login.html 登录，dev_hub.html 联调枢纽，police_terminal.html 警用大屏，
  vehicle_terminal.html 车主端，还有若干说明 txt
· 一大坨 JS：主要是 police_overview.js（警用逻辑）、traffic_microsim.js（仿真）、
  signal_coordination_core.js（信号演示）、dev_shim.js（开发用假数据，别当真接口）
· src\：Java 后端源码（Spring Boot）
· scripts\：下载地图、生成 OSRM、启动 OSRM、等 OSRM、自检之类 PowerShell
· data\：放重庆地图 pbf、生成好的 OSRM 文件（没有的话要先按「阅读我」里步骤做）
· docker-compose.mysql.yml：可选，用 Docker 起一个 MySQL 给项目用（端口 3307）
· apache-maven-3.9.9：可选自带 Maven，启动脚本会尝试自动用这个，没有就自己装 Maven

--------------------------------------------------------------------------------
三、后端这边「配了啥」—— 混个脸熟就行
--------------------------------------------------------------------------------
· 端口：后端默认 8080（在 src\main\resources\application.properties 里）
· 数据库默认：没用 MySQL 的时候，是内存里 H2，电脑一关后端数据就没了，适合演示
· 要用 MySQL：用启动脚本带 docker-mysql，或自己起容器后再用「后端-启动-DockerMySQL」那套
· 登录：POST /api/auth/login，用户名密码对了会返回 token，后面有的接口要在请求头里带
  Authorization: Bearer 那一串
· 算路接口：GET /api/route/driving?fromLat=&fromLng=&toLat=&toLng=
  这个故意做成不用登录也能调，方便地图画线；真正干活是后端去请求 OSRM（本机或公网）
· OSRM 地址：配置文件里有 routing.osrm.local-base-url，一般是本机 5000 或 5001 那种；
  启动脚本会写 data\osrm-published-endpoint.txt，并设环境变量让 Spring 对上端口
· 安全那块：WebSecurityConfig.java 里写了哪些路径不用登录——改接口时别顺手把放行改没了

--------------------------------------------------------------------------------
四、怎么一键跑起来（给演示的人）
--------------------------------------------------------------------------------
· 双击「启动全栈后端.cmd」：会新开一个黑窗口跑 OSRM，当前窗口跑 Spring
· 第一次用要先有地图数据：下载重庆地图数据.cmd → 首次生成OSRM数据.cmd（很慢，正常）
· 想检查 OSRM 和 8080 通不通：检查-全栈.cmd

--------------------------------------------------------------------------------
五、你要改后端时，最常打开的 Java 文件
--------------------------------------------------------------------------------
· 各种 *Controller.java：对外 URL
· RouteProxyService.java：真正去调 OSRM、失败再试公网的那套逻辑
· WebSecurityConfig.java：谁要登录、谁不用
· application.properties / application-docker-mysql.properties：端口、数据库、OSRM 地址

--------------------------------------------------------------------------------
六、和前端页面怎么配合（一句人话）
--------------------------------------------------------------------------------
· 页面是静态的，用浏览器直接打开文件也能看 UI，但要调登录、算路，最好本地起一个
  http 访问（比如 VS Code Live Server），后端也要在 8080 跑着
· 警用页里请求后端，默认写的是 http://localhost:8080
· 地图底图用的是 MapTiler 的 key，写在 police_overview.js / vehicle_terminal 里，
  跟后端无关，key 欠费了就换自己的或走脚本里备用的底图逻辑

--------------------------------------------------------------------------------
七、心里要有数：这是演示向的
--------------------------------------------------------------------------------
· 很多 KPI、滚动新闻、dev 模式下的假接口是演示用的，不是真交管实时数据
· H2 不持久；要上真库再上 MySQL 那套

--------------------------------------------------------------------------------
八、卡住了可以按这个顺序瞄一眼
--------------------------------------------------------------------------------
Docker 开了没 → OSRM 那个窗口还在不在 → data 里 OSRM 文件齐不齐 →
8080 能不能打开 → 看 spring-boot-last-run.log → 再跑检查-全栈.cmd
